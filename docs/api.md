### Основные эндпоинты

- `GET /recommendation/{user_id}` — получить рекомендации для пользователя.
- `POST /rule` — создать динамическое правило.
- `GET /rule` — получить список всех правил.
- `DELETE /rule/{id}` — удалить правило по ID.

Для каждого эндпоинта в Swagger описаны:
- параметры запроса,
- схемы запросов/ответов (DTO),
- коды ответов (200, 201, 204, 4xx, 5xx).
